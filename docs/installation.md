# Agent installation
Clone this repository locally. For Codex, copy `.agents/skills/design-research/` into your user or project skills directory supported by your Codex installation. For Claude Code, copy `.claude/skills/design-research/` into the corresponding Claude skills directory. Keep this repository accessible locally so referenced catalogue and methodology files can be read. Preserve existing project `AGENTS.md` and `CLAUDE.md`; add a pointer rather than replacing them. Test skill discovery and browser access in both agents. No automatic cross-project integration is implied by publication.

# Research orchestration
1. Classify task and select a route from `routing/routes.json`.
2. Inspect target project and select relevant sources.
3. Browse real examples with dates and deep links when tools allow.
4. Generate evidence-backed options and select a suitable approach.
5. Implement only with permission and validate actual changes.
6. Store findings and update pattern index when warranted.

Use a lightweight path for small copy fixes and deeper research for redesigns. No automatic browsing is provided by this repository. Agent environments need their own browser/search tools.
